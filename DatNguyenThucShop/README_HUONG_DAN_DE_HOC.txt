DATNGUYENTHUCSHOP - HUONG DAN CHAY WEBSITE

1. Giai nen thu muc DatNguyenThucShop.
2. Mo file index.html bang trinh duyet hoac mo thu muc bang VS Code va dung Live Server.
3. Cac trang HTML:
   - index.html: Trang chu
   - products.html: Danh sach san pham
   - product-detail.html: Chi tiet san pham
   - cart.html: Gio hang
   - checkout.html: Thanh toan
   - login.html, register.html, profile.html: Tai khoan

TO CHUC MA NGUON
- header.html va footer.html: phan dau trang va chan trang duoc nhung bang iframe.
- css/style.css: mau sac va quy tac co ban.
- css/components.css: nut bam, bieu mau va cac thanh phan dung lai.
- css/bo-cuc.css: bo cuc trang, uu tien CSS Grid.
- js/: xu ly gio hang, san pham va tai khoan.

GHI CHU
- Cac class CSS duoc doi sang ten tieng Viet khong dau de de nho.
- Da loai bo cac quy tac @media va giao dien rieng cho mobile theo yeu cau.
- Du lieu mau va gio hang luu bang localStorage; chua ket noi co so du lieu that.
- Mot so anh va Font Awesome duoc tai tu internet.


THANH DIEU HUONG DUONG DAN
- Cac trang con hien thi duong dan vi du: Trang chu > San pham > Chi tiet san pham.
- CSS cua thanh duong dan nam trong css/style.css, class .thanh-duong-dan.
- Sua ten muc va lien ket trong tung file HTML neu can.
